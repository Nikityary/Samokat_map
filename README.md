# Samokat_map

Карта кодов домофонов для курьеров Самоката (Владимир, районы Коммунар
и Заклязьменский): клиенты оставляют коды от подъездов с неработающими
домофонами — вместо блокнота они отмечаются на карте и доступны всей команде.

- Приложение: [`domofon-map/`](domofon-map/) (Vite + Leaflet + Supabase)
- Схема базы и политики доступа: [`supabase/schema.sql`](supabase/schema.sql)

Запуск и настройка — в [README приложения](domofon-map/README.md).
