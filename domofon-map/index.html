Нужна настройка

Не заданы ключи Supabase.

  1. Создайте проект на supabase.com.
  2. Выполните supabase/schema.sql в SQL Editor.
  3. Скопируйте .env.example в .env и подставьте Project URL и anon key (Settings → API).
  4. Перезапустите npm run dev.

Подробности — в README проекта.
