# Домофоны — карта кодов подъездов (Владимир: Коммунар и Заклязьменский)

Прототип сайта для курьеров Самоката: карта, на которой можно отмечать дома
с неработающими домофонами и записывать коды подъездов.

## Запуск

```bash
cd domofon-map
npm install
npm run dev        # http://localhost:5173
npm run build      # production-сборка в dist/
```

## Возможности

- **Карта** (Leaflet + OpenStreetMap) с центром на районе Коммунар; пунктирная рамка — ориентир по Коммунару и Заклязьменскому.
- **Добавление точки**: кнопка «＋ Добавить» → клик на карту. Адрес подставляется автоматически (Nominatim reverse-geocoding), редактируется вручную.
- Поля записи: адрес/ЖК, подъезд, код домофона, комментарий, флаг «код мог измениться (требует проверки)».
- Код показан прямо на маркере («пилюля» 🔑); устаревшие точки оранжевые.
- **Боковой список** записей с поиском по адресу; клик по записи — переход к точке.
- **Редактирование/удаление** через попап на карте.
- **Экспорт/импорт JSON** — способ переносить данные между устройствами (сейчас хранение локальное, в localStorage браузера).
- Адаптивная вёрстка (на телефоне список — снизу).

## Структура

- `index.html` — разметка
- `src/main.js` — карта, маркеры, формы, поиск, импорт/экспорт
- `src/storage.js` — обёртка над localStorage (легко заменить на серверное API)
- `src/style.css` — стили
