# Домофоны — карта кодов подъездов (Владимир: Коммунар и Заклязьменский)

Сайт для курьеров Самоката: на карте отмечены дома, у каждого дома — список
подъездов, у подъезда — коды домофонов, которые оставили клиенты.
Данные общие для всех сотрудников (Supabase), вход — по личному аккаунту.

## Как пользоваться

1. Войдите (или зарегистрируйтесь) по email/паролю.
2. Кликните на дом на карте (контуры домов — из OpenStreetMap).
3. Если число подъездов ещё не задано — укажите его один раз, оно станет общим для всех.
4. Выберите подъезд → смотрите коды или добавьте свой («＋ Добавить код»).
5. Дома с кодами помечены пилюлей 🔑 с числом записей; поиск по адресу — в шапке.

## Возможности

- **Контуры домов и подъезды из OSM** (`public/osm-buildings.json`); у части домов
  подъезды уже размечены в OSM — их номера используются автоматически.
- **Общая база**: записи и число подъездов хранятся в Supabase, изменения
  появляются у всех в реальном времени.
- **Личные аккаунты**: данные доступны только после входа (RLS).
- Поля записи: код домофона, комментарий, флаг «код мог измениться (требует проверки)».
- Редактирование/удаление записей, уточнение адреса дома.
- **Экспорт/импорт JSON** — резервная копия и перенос записей.
- Адаптивная вёрстка (на телефоне панель — снизу).

## Настройка Supabase (один раз)

1. Зарегистрируйтесь на [supabase.com](https://supabase.com) и создайте проект
   (бесплатного тарифа достаточно).
2. **SQL Editor → New query**: выполните [`supabase/schema.sql`](../supabase/schema.sql)
   из корня репозитория. Если база уже создавалась по старой версии схемы —
   выполните [`supabase/migration-buildings.sql`](../supabase/migration-buildings.sql).
3. **Authentication → Providers → Email**: отключите **Confirm email**,
   чтобы коллегам не нужно было подтверждать почту.
4. Скопируйте `.env.example` в `.env` и подставьте значения из
   **Settings → API**: `Project URL` → `VITE_SUPABASE_URL`,
   `anon public` (или publishable key) → `VITE_SUPABASE_ANON_KEY`.
   Ключ не секрет: данные защищает RLS, без входа их не прочитать.
5. При желании можно отключить «Allow new users to sign up» и создавать
   аккаунты коллегам вручную (**Authentication → Users → Add user**).

## Запуск

```bash
cd domofon-map
npm install
npm run dev        # http://localhost:5173
npm run build      # production-сборка в dist/
```

## Обновление данных OSM

Дома и подъезды выгружаются из Overpass API скриптом:

```bash
node scripts/fetch-osm.mjs
```

Скрипт пробует несколько зеркал Overpass и сохраняет результат в
`public/osm-buildings.json`. Данные OSM доступны по лицензии ODbL.

## Структура

- `index.html` — разметка (включая экран входа)
- `src/main.js` — карта, контуры домов, панель подъездов и записей
- `src/auth.js` — экран входа/регистрации
- `src/supabase.js` — клиент Supabase (ключи из `.env`)
- `src/storage.js` — слой данных поверх Supabase (+ realtime-подписка)
- `src/osm.js` — загрузка контуров домов
- `scripts/fetch-osm.mjs` — выгрузка домов и подъездов из OSM
- `src/style.css` — стили
- `../supabase/schema.sql`, `../supabase/migration-buildings.sql` — схема базы
